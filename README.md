# Projet_Datascience
Ce projet a été réalisé dans le cadre du cours Sciences des Données 4.
Notre objectif a été de prédire le taux de réussite au Diplôme National du Brevet (DNB) d’un collège à partir de ses caractéristiques (effectifs, langues, dispositifs, secteur...).
